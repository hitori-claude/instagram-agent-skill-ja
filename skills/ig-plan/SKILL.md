# ig-plan

司令塔です。このパックのほかのスキルは実行役で、このスキルは何を実行するかを
決めます。週に1回、毎週同じ曜日に使います。

## 用意してもらうもの

`~/.claude/instagram/voice.md`、`swipe.md`、`log.md` があれば読みます。
ネタ帳（swipe.md）は `/ig-viral` で集めた、本人のジャンルで今どの型が
当たっているかの証拠です。このファイルに書いてあることより優先します。
log.md は、ここ2週間と同じテーマを繰り返さないために見ます。

ファイルがなければ、次の4つを聞いて書き留めます。

1. 何を、誰に売っているか。
2. 知られたいテーマを3つか4つ。
3. 今週実際にあったこと。お客さんとの電話、数字、失敗、作ったもの、
   誰かとの言い合い。投稿のネタはここから出てきます。
4. 見てもらいたいアカウントを10個。

## 何を投稿するか

週4〜5投稿で、そのうち3本以上はリールにします。フォロワー以外に安定して
届くのはリールだけです。カルーセルはすでにフォローしてくれている人に深く届きます。
ストーリーズは毎日で、別に計画します。

週の中で混ぜます。同じ種類を2日続けません。

| 種類 | 頻度 | 役割 |
| --- | --- | --- |
| **実績** | 週1 | 実際に起きたことを数字つきで。リール。 |
| **ノウハウ** | 週1〜2 | 見た人が今日できることを1つ。リールかカルーセル。 |
| **意見** | 週1 | フォロワーが減るかもしれない立場をとる。リール。 |
| **エピソード** | 2週に1 | 代償があった場面の話。リール。 |
| **商品案内** | 2週に1 | 売っているものを、言い訳せずそのまま。カルーセルかストーリーズ。 |

各枠には、テーマ、今週実際にあったことから取った具体的な切り口、形式、
`ig-reel/hooks.json` のフック型の番号を書きます。テーマではなく切り口です。
「AI」は計画になりません。「下書きに残っていたAIっぽい言い回しのせいで
失注した提案書の話」ならリールになります。

## いつ投稿するか

見てほしい人が起きていて、仕事中ではない時間に出します。日本の一般向けなら
平日の夜（20〜22時ごろ）や昼休み（12時台）、ビジネス向けなら通勤時間の朝
（7〜8時台）がよく使われます。

ただし、これははっきり伝えます。**時間帯より、最初の2秒のほうがずっと大事です。**
反応がいいリールは何日も表示され続けますし、時間がよくても反応がなければ
埋もれます。フックがまだ効いていないうちに投稿時間を調整しているなら、
磨く場所が違うと伝えます。

本人と見てほしい人の住んでいる地域が違うなら、相手の時間に合わせます。

## コメント回り（省略しない）

1日20分。投稿の後ではなく前にやります。10アカウントのリストを作ります。

- **リーチ用5つ** ：本人がほしいフォロワーを持っていて、いいコメントが
  見られるアカウント。コメントが200件たまる前の、早いうちに書きます。
- **同業3つ** ：同じくらいの規模、同じジャンル。お互いに返し合える相手です。
- **お客さん候補2つ** ：実際に買ってくれそうな人。DMの前に何週間もコメントを重ね、
  コメントで売り込みはしません。

リストは `/ig-comment` に渡します。

```
月  コメント回りだけ  （20分、リストは下）
火  20:30  リール      実績      #5  Time Collapse      5時間かかっていた提案書が20分に
水  ストーリーズ＋コメント回り
木  21:00  カルーセル  ノウハウ  Job B キャプション  契約書の文言を4枚で解説
金  20:30  リール      意見      #2  Negative Command   初回ヒアリングの通話はやめていい
土  なし
日  19:00  リール      エピソード #21 Mid-Sentence      返金依頼のメールが来た日

ストーリーズ  毎日3〜5枚、木曜に質問ボックス。

コメント回り  （リーチ5 / 同業3 / お客さん候補2）
  ...

「火曜の分を書いて」と言ってもらえれば下書きします。
```

計画は `~/.claude/instagram/plan.md` に書き出して、ほかのスキルが読めるようにします。
予約投稿や投稿はどこにもしません。これは計画で、実行するのは本人です。
