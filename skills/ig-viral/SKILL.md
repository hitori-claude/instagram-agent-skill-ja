# ig-viral

調べるためのスキルです。ほかのスキルは書くのが仕事で、これは見に行くのが仕事です。
毎日ではなく月1回で十分です。型は1シーズンくらいもちます。

このフォルダには道具が1つあります。

```bash
python swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

## これをやる意味になっている考え方

**再生数そのものは証拠になりません。** フォロワー200万人のアカウントで40万再生なら、
静かな1日です。フォロワー4,000人のアカウントで40万再生なら、何かを見つけています。
その「何か」はまねできます。

なので、ここでは全部を**倍率**で並べます。再生数を、そのアカウントの最近の再生数の
中央値で割った数です。3倍をこえたら手がかりです。1.5倍未満はそのアカウントの
いつもの日で、数字がどれだけ大きく見えても何も教えてくれません。

集めるのは、**本人のアカウントの規模の10倍くらいまで**のアカウントにします。
フォロワー200万人で効く型は、200万人いるから効いていることが多いです。

## ステップ1: アカウントを選ぶ

6〜12個のアカウントを本人に聞くか、こちらから出して了承をもらいます。

- **同じジャンル4つ**: 同じジャンル、同じ商品、少し先を行っている人。
- **となりのジャンル4つ**: ジャンルは違うが、見ている人が同じ。たとえば朝活の人なら
  時短家事や家計管理。ジャンル内でまだ誰もやっていない形を借りられるのはここです。
- **大きいアカウント2〜4つ**: ずっと大きいアカウント。形だけ見ます。投稿頻度や
  口調はまねしません。

本人の**保存済み（コレクション）**も開いてもらいます。いちばん早くて、いちばん
関係のある材料です。本人の好みで、もう選ばれています。

## ステップ2: 見に行く

このセッションで使えるブラウザ操作の道具を使います。アプリ内のブラウザ、本人の
Chrome につながった拡張機能、画面操作の道具など。API はありませんが、要りません。
読める量だからです。

**ゆずれないルール:**

- **本人の代わりに Instagram にログインしない。パスワードも聞かない。** ログインが
  必要なページなら、ログインしているのは本人です。本人がいるところでブラウザを
  操作するか、内容を貼ってもらいます。
- **これは「読む」であって「スクレイピング」ではありません。** 10アカウント、
  各10数本を、人が見る速さで。大量の自動収集は Instagram の利用規約違反で、
  アカウントが操作制限を受けます。クローラーを作らない、収集サービスを使わない、
  裏で繰り返し回さない。
- **まねするのは型だけで、動画はまねしない。** フックの形、構成、長さ、カットの
  リズム。台本、声、編集はまねしません。ネタ帳の各行には出どころのアカウントを書きます。

**1本ごとに書き取るもの**（投稿者の言葉のまま）:

| 列 | メモ |
| --- | --- |
| アカウント | @ハンドル |
| フォロワー | プロフィールから。「4.8万」のままで大丈夫です |
| 中央値 | 最近の12本をざっと見て、真ん中の再生数 |
| 再生数 | このリール |
| フック | 最初の一言。話した言葉か画面の文字を、言い間違いも含めてそのまま |
| 画面の文字 | 最初のテロップ（声と違う場合） |
| 長さ | 秒 |
| お願い | 最後に何を頼んでいたか |

大事なのは中央値です。これがないと、結局フォロワー数で並べることになります。
このスキルはそれをやめるためにあります。

**Instagram で十分見られないとき:** 同じフックの型は YouTube ショートでも使われて
います。YouTube は再生数と字幕が公開されていて、ログインも要りません。2つ目の
材料として正当で、話したフックも取りやすいです。

```bash
# チャンネルのショートの再生数
python -m yt_dlp --flat-playlist --playlist-end 40 -J ^
  "https://www.youtube.com/@HANDLE/shorts" > channel.json

# ショート1本の最初の一言（自動字幕から）
python -m yt_dlp --skip-download --write-auto-subs --sub-langs "ja.*" ^
  --sub-format json3 -o hook "https://www.youtube.com/watch?v=VIDEO_ID"
```

タイムスタンプが3.0秒より前の字幕を全部取ります。それが書かれたフックではなく、
実際に話されたフックです。日本語の自動字幕は区切りや漢字がずれることがあるので、
動画を聞いて直してから使います。

## ステップ3: 並べる

先頭に列名の行があるタブ区切りのファイル（TSV）を埋めて、スクリプトを回します。
列名は日本語でも英語でも大丈夫です。CSV でも読めます。

```
アカウント	フォロワー	中央値	再生数	フック
@asa_katsu_mama	4.8万	1.1万	41.2万	最初の30本は伸びなくて当たり前です
```

数字は `3400` `3,400` `３，４００` `1.2万` `12万3千` `12K` `1.5M` `約2万回` の
どれでも読めます。読めない行は飛ばして、その旨を表示します。

```bash
python swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

倍率を計算し、`/ig-reel` が使う26のフックの型で名前を付け、`hookscore.py` で
フックに点数を付け、上位3分の1と下位3分の1の違いを表示します。フックの長さは
日本語なら文字数、英語なら単語数で数えます。

## ステップ4: 意味を、慎重に伝える

伝えるのは3つだけです。

1. **上位3分の1に多い型**を、数と一緒に。6アカウントで2つの型が4回ずつ出ていれば
   発見です。1つの型が2回なら、まだ発見ではありません。
2. **上位3分の1に共通していて、下位にはない作りの特徴**。フックの長さ、オチが
   映像で見せるものか、最初のコマが動いているか、お願いがどこにあるか。
3. **未分類の行。** 型の名前が付かなかったフックは、ただのノイズか、`hooks.json` に
   まだない型です。手で読みます。ここが出力の中でいちばん価値のある列で、
   スクリプトが数を表示するのはそのためです。

そのあと、本数と確からしさをふつうの言葉で伝えます。6アカウントで40本なら
何か言えます。12本では言えません。そう言えるかどうかが、調査と占いの違いです。

## ステップ5: 撮れるものにする

上位3つの型について、**本人の版**を書きます。本人の体験、本人の数字を、効いている
形に入れます。それぞれ型の番号を決めた状態で `/ig-reel` に渡します。

「このリールみたいなのを作って」で返さないこと。明日そのまま言えるフックの一文で
返します。

## 出力

```
スワイプファイル  ·  リール 38 本  ·  7 アカウント  ·  基準: アカウントの中央値

外れ値（3倍以上）
  38.4倍  フック 86  #3  誰も教えてくれない   @acct_a    412,000（中央値 10,700）
  11.2倍  フック 79  #9  パクってください     @acct_c    180,000（中央値 16,100）
  ...

多く出ている型
  #3 誰も教えてくれない   上位で5回、下位で0回
  #2 やめろ型             4回
  フックの長さの中央値    上位 14字、下位 31字

未分類（6）
  2つは同じ形で、hooks.json にありません。誰かのコメントを読み上げて始まる型です。
  追加する価値があります。

あなたの版
  #3 「誰も教えてくれないけど、最初の20件の提案は落ちて当たり前です。」
  ...
```

ネタ帳は `~/.claude/instagram/swipe.md` に書き出します。`/ig-reel` と `/ig-plan` が
両方これを読みます。一度回せば、ほかのスキルは決まりきった型ではなく、本人の
集めた証拠をもとに動くようになります。それがこのスキルの狙いです。

このスキルは投稿、フォロー、いいね、メッセージを一切しません。読むだけです。
