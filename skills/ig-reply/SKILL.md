# ig-reply

自分の投稿のコメント欄で、どこまで届くかが決まります。返信するたびに投稿への
反応が1つ増え、特に投稿から1時間以内の返信が効きます。インスタでは返信を
リールで返すこともできて、これはあまり使われていない一番の手です。

ただ、コメントによって価値が違うので、このスキルは書く前に仕分けます。

## 用意してもらうもの

コメントを貼ってもらいます。できればアカウント名つきで。スクショでも大丈夫です。
ブラウザツールでコメント欄を読み取ることはしません。

## まず仕分け

全部のコメントを6つの箱に分け、それぞれの件数を伝えます。

| 箱 | 中身 | 返し方 |
| --- | --- | --- |
| **合言葉** | コメントしてと頼んだ言葉 | 約束したものを、手作業か、設定済みの公式機能・認められたツールで送る |
| **見込み客** | あなたが解決できる悩みを書いている人 | 公開の場でちゃんと答えて、最後に入り口を1つ |
| **中身あり** | データを足す、反対する、話を広げる | コメント欄で一番長い返信 |
| **質問** | 多くの人が持っていそうな質問 | 返信だけで終わらせず、リールにする |
| **応援** | 「🔥」「最高です」、友だちのタグ付け | いいねと、ひとこと（10〜20文字くらい）まで |
| **雑音** | 宣伝、スパム、悪意、釣り | 何もしない、または1行で終わり |

この順番で書き、価値がなくなったところで止めます。

## 見落とされがちな一手

コメントの質問が、ほかの30人も持っていそうなものなら、**リールで返信します**。
インスタはそのコメントを新しい動画にステッカーとして付け、質問した人にも
通知が届きます。実際に求められている質問が、フックがもう書かれた状態の
投稿になります。当てはまる質問には全部しるしをつけ、`/ig-reel` に
フック型 #16（The Verbatim Question）として渡します。

## 返信の書き方

- **聞かれたことに答えます。** やり方を聞かれたら、返信の中でやり方を書きます。
  コメントで済む答えのために「DMください」と誘導しません。
- **相手の名前は最初に1回だけ。** 「〇〇さん」で、「！」は付けません。
- **長さを相手に合わせます。** 10文字のコメントに4行の返信はしません。
- **敬語かタメ口かは、自分の普段の口調でそろえます。** 相手がタメ口でも、
  自分が敬語のキャラなら敬語のままで大丈夫です。返信ごとに口調が変わると目立ちます。
- **全部に同じ文面を貼らない。** 「ありがとうございます！」の連打は、読んだ人にも
  コピペだとわかります。短くても1件ずつ少し変えます。
- **批判には：** まず正しい部分を相手の言葉で認め、それから自分の考えは曲げません。
  消さない、言い訳っぽくならない、同じスレッドで2回返さない。
- **アンチには：** 何も返しません。返信すればそれが相手の露出になり、相手が
  ほしいのはまさにそれです。悪質なら非表示にします。インスタのコメント管理機能
  （非表示、制限、NGワード）はそのためにあって、使っても負けではありません。
- **見込み客には：** 公開の場でちゃんと答えます。入り口は最後の1文だけで、
  売り込みではなく「よければ〜」という手助けの申し出にします。公開で答えたことが、
  次の人がDMをくれる理由になります。

## 合言葉コメント

投稿で合言葉コメントをお願いしていたなら、そのコメントがこの投稿の目的そのものです。
1件1件が、手を挙げてくれた人です。それぞれに返信して、約束したものを送ります。
インスタ公式の機能や認められた外部ツール（ManyChat など）で自動返信を設定して
あるなら、そう伝えて任せます。なければ手作業で、この件数なら手作業で問題ありません。

送るのは早めにします。DMには、相手からの反応（コメントやメッセージ）から
24時間以内なら送れる、という時間の枠があり、自動ツールもこの枠で動きます。
細かい条件は変わることがあるので、使っているツールの説明も確認しておくと安心です。
コメントしていない人にまとめてDMを送ることはしません。

## 出力

1ブロックで、箱ごとにまとめます。どの返信もそのまま貼れる形で、
`/ig-human` に通した状態で出します。

```
返信  ·  84件  ·  合言葉41、見込み客2、中身あり3、質問2、応援34、雑音2

合言葉  （41）  文言を送る。1行ずつ、同じ温度で、コピペにはしない。

見込み客
@handle  「うちも6月にまったく同じことがありました」
> うちが解決したのは、支払いのタイミングを「承認時」から完全に外したことでした。
> よければ実際の文言をお送りしますね。

質問 → リール
@handle  「相手がサインを断ってきたらどうしてますか？」
  このコメントにいいね34。返信ではなくリールにする内容です。フック型 #16。

雑音  （2）  スキップ。返信すると相手の露出になります。
```

最後に確認を挟みます。本人が「OK」と言うまで何も投稿しません。
返信を貼るのは本人です。
