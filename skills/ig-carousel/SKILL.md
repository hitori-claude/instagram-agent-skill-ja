# ig-carousel

カルーセルはフィードの中で一番長く見てもらえる形式です。スクロールは
反応に数えられませんが、スワイプは反応に数えられるからです。
もう一度チャンスがあるのも特徴で、1回目に反応しなかった人に、2枚目以降から
表示し直されることがあります。なので2枚目も単体で成り立つように作ります。

1つのアイデアを手順に分けると強く、キャプションを細切れにしただけだと弱くなります。

## リールではなくカルーセルにするとき

アイデアに**順番があって、読み返したくなるもの**ならカルーセルです。
手順、いくつかのパーツでできた考え方、ビフォーアフター、スクショして
とっておきたいリストなど。動きがある、顔が要る、結果が起きる瞬間を
見せたい、というものはリールです。

主張が1つだけなら、どちらでもありません。`/ig-reel` に回し、そう伝えます。

## 構成

6〜10枚。上限は20枚ですが、20枚はほぼ誰も最後までめくりません。
5枚未満だとスワイプが始まりません。

```
1        表紙      フック。日本語で15文字前後まで。サムネイルの大きさでも
                   読める文字サイズ。その下に「これを読むと何がわかるか」を1行。
2        なぜ大事か  なぜ読む価値があるかを1文で。この2枚目は「2つ目の表紙」
                   でもあるので、前置きにしない。
3〜N     1枚1アイデア  見出しは10〜20文字、その下の本文は60文字まで。
                   段落が要るなら、それは2枚に分ける。
N+1      まとめ    全体をリストで1枚に。スクショされるのはこの1枚。
最後     行動      お願いは1つだけ。保存、合言葉コメント、フォローのどれか1つ。
```

## 文面のルール

- **結果の8割は表紙で決まります。** 短く、大きく。表紙でスワイプされなければ、
  中身がどれだけよくても読まれません。
- **プロフィール画面の切り取りを前提にします。** プロフィールのグリッドは縦長に
  切り取られ、その比率はこれまで何度か変わっています。1080×1350で作り、
  表紙の文字は四辺から120pxの余白より内側、中央寄りに置けば、切り取りの
  違いは気にならなくなります。
- **ページ番号を入れます**（3/8）。終わりが見えると最後までめくられやすくなります。
- **段落を置かない。** 60文字で言えなければ分けます。日本語は1枚に詰め込みがち
  ですが、スマホで読むと字が小さく、読み飛ばされます。改行は意味の切れ目で。
- **まとめの1枚がスクショされて、友だちに送られます。** シェアは取れる中で一番
  強いシグナルです。前の枚を見ていなくても読めるように作ります。
- **全部の枚にアカウント名を入れます。** 右下か左下に小さく。スクショは
  あなたの名前抜きで広がっていきます。
- **少なくとも表紙には代替テキストを設定します。** 読み上げ機能とインスタの
  両方がこれを読みます。
- **敬語かタメ口かは全部の枚でそろえます。** 途中で混ざると素人っぽく見えます。

## 画像を作る

インスタの推奨は1080×1350（4:5）、JPEGかPNG、最大20枚です。
HTMLで作って1枚ずつ書き出します。

```bash
# 1枚につき <section> を1つ、1080x1350、page-break-after: always
# そのあと Chrome headless の --print-to-pdf か、普段使っている HTML→画像 の方法で書き出す
```

HTMLは `width:1080px; height:1350px`、差し色は1色、文字は32px以上にします。
スマホでは実寸の3分の1くらいで見られるからです。日本語フォントは
Noto Sans JP など、太字がきれいに出るものを使います。プロジェクトに
ブランド用のスキルやデザインルールがあればそれを使い、配色を勝手に作りません。

## 出力

まず1枚ずつの文面を番号つきリストで出します。10秒で読めて、画像にする前に
本人が直せる形です。次に**キャプション**。カルーセルのキャプションは
`/ig-caption` のJob Bです。表紙で文字数を使い切っているので、キャプションが
説明の役を担います。

文面もキャプションも `/ig-human` に通します。画像を作るのは、本人が文面に
OKを出してからです。

```
カルーセル  ·  8枚

1  表紙     請求トラブルを防いだ1行
            今は全部の契約書に入れています。
2  なぜ     納品OKをもらった9日後に、返金してほしいと言われました。
3           何が書いてあるか
            支払いは「承認時」ではなく「納品時」。
...
7  まとめ   4つの文言を順番に1枚で。
8  行動     「契約」とコメントしてくれた方に、文言をDMで送ります。

キャプション：Job B、1行目にフック、お願いは1つ、ハッシュタグ3つ。
```

アップロードはしません。投稿は本人がします。
