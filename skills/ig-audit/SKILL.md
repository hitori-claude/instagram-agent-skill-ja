# ig-audit

そのアカウントで何が効くかを正直に教えてくれるのは、そのアカウント自身の
数字だけです。インスタのノウハウ本のルールも、このパックのルールも、
あくまで「たぶんこうだろう」という前提です。本人の直近30投稿が証拠になります。

## 用意してもらうもの

手元にあるものでかまいません。

- 投稿ごとのインサイト：再生数、リーチ、インタラクション、視聴時間、保存、
  シェア、フォロー、リーチのうちフォロワー外の割合。スクショで大丈夫です。
- または、直近で一番伸びたリールと一番伸びなかったリールの「視聴維持率」
  のグラフ。このスクショ1枚が、ほかの数字全部より役に立ちます。
- それもなければ、投稿と再生数の一覧だけでも最初の見立てはできます。

`~/.claude/instagram/log.md` があれば読みます。各投稿でどのフック型を
使ったかが記録されています。

## 実際に見る数字

再生数そのものは、画面の中で一番あてにならない数字です。ほとんどが
「もともとのフォロワー数」で決まるからです。代わりに次を計算し、
計算の過程も見せます。

| 指標 | 出し方 | わかること |
| --- | --- | --- |
| **伸び倍率** | 再生数 ÷ そのアカウントの再生数の中央値 | 本当に当たったのか、いつも通りだったのか |
| **フォロワー外リーチ** | リーチのうちフォローしていない人の割合 | 外に届いたかどうか |
| **3秒維持率** | 3秒時点で残っている人 ÷ 見始めた人 | フックが効いたか。フックの成績表です |
| **平均視聴時間** | インサイトの数字そのまま | 中盤がもったか |
| **リーチあたりのシェア** | シェア数 ÷ リーチ | 取れる中で一番強いシグナル。シェアは「自分の名前で人に勧める」行為です |
| **リーチあたりのフォロー** | フォロー数 ÷ リーチ | プロフィールが注目をフォローに変えられたか |

並べる順番は再生数ではなく、伸び倍率とリーチあたりのシェアです。
4,000再生でシェア90件のリールは、60,000再生でシェア11件のリールに勝っています。

## 次に、差を探す

上位5本と下位5本を並べて、何が分けているかを見ます。本人にとって
うれしくない結論でも、そう出たらそう書きます。

- **3秒維持率。** ここで上位と下位に差があるなら、原因はフックだけです。
  ほかの要素は気にしなくていいです。
- **フック型。** `ig-reel/hooks.json` のどの番号が上位5本に入っているか。
- **形式。** リール、カルーセル、画像1枚。
- **長さ。** 15秒未満、15〜30秒、30〜60秒、60秒超に分けます。
- **テーマ。**
- **投稿後1時間以内にコメント返しをしたかどうか。**
- **曜日と時間帯。** これは**最後に**、ほかで何も出なかったときだけ見ます。
  原因になっていることはまずありませんが、みんなここを原因にしたがります。

結論は「主張＋根拠」の形で書き、どのくらい確かかも添えます。
30投稿あれば傾向は見えます。6投稿では見えません。そのときは
無理に傾向を作らず、「まだ判断できない」と書きます。

## 何ヶ月も遠回りしないための区別

**再生されたのにフォローが増えないリールは、失敗作ではなくプロフィールの問題です。**
再生されないリールはフックの問題です。何かを提案する前に、この2つを分けます。
フォロワー外リーチが高く、リーチあたりのフォローが低いなら、フックの
書き直しはやめて `/ig-profile` に進みます。

## 出力

```
振り返り  ·  31投稿  ·  6/12〜9/5  ·  再生数の中央値 4,100

伸び倍率 上位5本
  18.2倍  #3  Nobody Tells You  「誰も教えてくれない」  74,600再生  フォロワー外62%  3秒維持71%  シェア128
   6.4倍  #1  Cost Confession   「失敗の告白」          26,300再生  フォロワー外48%  3秒維持64%  シェア71
  ...

下位5本
   0.3倍  #11 Numbered          「〇選」                 1,200再生  フォロワー外9%   3秒維持31%  シェア2
  ...

データからわかること
1. 3秒維持率でほぼ説明がつきます。上位5本の平均66%、下位5本は33%。
   ほかに気にしていることは、全部最初の2秒より後の話です。
2. 自分がやらかした話の投稿は平均8.1倍、それ以外は0.9倍。n=5。
   今回一番強いシグナルで、差もはっきりしています。
3. 「おすすめツール〇選」は再生だけ取れて、ほかが何もつきません。
   リーチは高いのにシェアもフォローもない。下位5本のうち3本がこれです。
4. 曜日の差は出ていません。火曜と金曜の平均はブレの範囲内です。
   ここの調整はやめていいと思います。

やめる：〇選系。
増やす：自分が払った代償と、具体的な数字が入っている話。
```

結論は `/ig-plan` に渡して、来週の計画を一般論ではなく本人の数字で組みます。
`/ig-viral` にも渡して、ネタ帳をこのアカウントで効いている型に絞ります。
