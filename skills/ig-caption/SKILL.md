# ig-caption

このフォルダには道具が1つあります。

```bash
python caption.py caption.txt
python caption.py caption.txt --keywords "朝活,時短レシピ"
```

フィードでの見え方をそのまま表示します。「…続きを読む」の前に見える部分を枠で囲み、
残りはタップしないと読めない扱いです。自分の書いた文章より先に、まずこの枠を読みます。

### 見える範囲について（目安です）

日本語のフィードは「文字数」ではなく「表示幅」と「行数」で切れます。全角は半角の
約2倍の幅をとります。このツールは次のように仮定しています。

- スマホの1行は全角26字ぶん（半角52）
- 見えるのは2行。1行目の頭にユーザー名、2行目の最後に「…続きを読む」が入る
- なので改行なしなら、本文で見えるのは全角で約39字
- 改行すると、その行の残りは使えません

機種、文字サイズ、ユーザー名の長さで前後します。ぎりぎりを狙わず、余裕を持たせる
ための数字です。幅は `--truncate`（半角換算）で変えられます。

## 最初に、このキャプションの役割を決めます

ここを飛ばすとキャプションはだいたい失敗します。

**役割A: 動画がもうつかんでいる。** リールは最初の2秒で、声と画面の文字でフックを
出しています。キャプションは2つ目のフックではありません。動画と張り合うと両方負けます。
役割は、お願い、お願いに納得してもらうための背景、検索される言葉です。

**役割B: キャプションが本体。** 写真、1枚画像、続きが気になるカルーセルの表紙など。
この場合は1行目がフックで、リールのフックと同じ考え方です。具体的に、短く、
文の途中ではなく「続きが気になる所」で切れるようにします。

どちらを書くのか確認します。強いフックのあるリールなら、Aで書いて理由を伝えます。

## 形

```
1行目       見えるのは全角で約39字。役割Aならお願いをそのまま。役割Bならフック。
            あいさつ、ハッシュタグ、絵文字から始めない。
本文        短い段落を2〜6個。段落の間は1行あける。検索されたい言葉はここに入れる。
お願い      1つだけ。キーワードをコメント、保存、DM のどれか1つ。
ハッシュタグ 一番下に5個まで。なしでもよい。
```

上限は2,200字ですが、そこまで要る投稿はほぼありません。タップさせて600字で
中身を渡すほうが、1,800字書くより強いです。

## ハッシュタグの正直な話

ハッシュタグはもう、届く範囲を広げる道具ではありません。仕様でもそう示されました。
**2025年12月18日から、ハッシュタグは1投稿5個までになりました**（以前は30個）。
公式の @Creators は、汎用タグをたくさん付けるより、絞ったタグを5個以内にしたほうが
成果につながる、という趣旨で説明しています。Adam Mosseri 氏も2025年2月に、
ハッシュタグは届く範囲を増やすものではなく「ラベル」だと話していました。

なので、5個まで、具体的に、話題のラベルとして使います。メモ帳に30個のタグを
貯めているなら、それはもう重りです。チェックでも FAIL になります。

`#いいね返し` `#フォロー返し` `#相互フォロー` `#おすすめ` `#バズれ` `#fyp` は
何も説明していません。外します。

ハッシュタグの # は半角で書きます。全角の ＃ はタグにならないことがあるので、
チェックで WARN を出します。`#朝活` `#時短レシピ` のような日本語タグは数えられます。

## ハッシュタグより検索語のほうが大事です

Instagram の検索はキャプションの文章を読みます。見つけてほしい言葉は、人が実際に
検索窓に打つ形で、自然な文の中に入れます。下に `#時短レシピ` を並べるより、
3行目に「時短レシピ」という言葉が文として入っているほうが効きます。

検索されたい言葉を2〜3個聞いて、チェックに渡します。

```bash
python caption.py draft.txt --keywords "時短レシピ,作り置き"
```

全角・半角や大文字・小文字の違いはそろえて比べます。ひらがなとカタカナの違い
（「れしぴ」と「レシピ」）や言い換えはそろえないので、実際に検索される表記で書きます。

## ルール

- **キャプションにリンクを貼らない。** キャプションのリンクは押せません。本文の URL は
  「この人はインスタに慣れていない」と伝わるだけです。プロフィールか DM に置きます。
- **お願いは1つ。** 2つあるのは、ないのと同じです。`caption.py` が数えます。
- **キーワードのお願いは、打ちやすい言葉にする。** 短い1語で、空白も絵文字もなし。
  動画の中でも声に出して言います。「コメントに『資料』と書いてください」は伝わります。
  「コメントに『家計簿テンプレートの使い方ガイド』と書いて」は打たれません。
  「DMで送ります」は自動返信の説明なので、お願いの数には入れません。
- **リンクがあるなら最初のコメントは別に書く。** そのことを最後の報告に書きます。
- **絵文字は句読点の代わりで、飾りではない。** 100文字あたり5個をこえると WARN です。
  日本語は1文字の情報量が多いので、英語版の基準（4個）より少しゆるめにしています。
- **代替テキストは20秒で書ける。** カルーセルと写真には書きます。読み上げ機能と
  Instagram の両方が読みます。

## 進め方

1. 役割AかBかを決めて伝えます。
2. 下書きします。
3. `/ig-human` にかけます。キャプションは短いので、AIっぽさがどこよりも目立ちます。
4. 検索語を付けて `caption.py` を回します。FAIL は全部直します。WARN は黙って
   流さず、直すか残すかを口に出して決めます。
5. コピーできる完成文を出し、そのあと報告を出します。

```
キャプション完成
役割:       A（リールがフックを持っている）
見える範囲: 全角で約39字のうち36字ぶん使用（目安）
お願い:     1つ、「資料」とコメント
ハッシュタグ: 3個
検索語:     「時短レシピ」3行目、「作り置き」5行目
チェック:   READY
```

投稿はしません。貼り付けるのは本人です。
