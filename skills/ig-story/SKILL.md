# ig-story

ストーリーズは小さいフィードではありません。フィードは知らない人に見つけてもらう
場所です。ストーリーズは、すでにフォローしている人が「この人から買っていいか」を
決める場所で、タップ1回がそのまま会話になる、インスタで唯一の場所です。

フォロワー以外にはほぼ見られないので、役割がまったく違います。広げるより、深める場所です。

## 1日の流れ

1日3〜7枚。7枚を超えるとタップで飛ばされる割合が上がり、最後のほうの枚は
誰にも見られません。そしてみんな、そこにお願いを置いてしまいます。

```
1       つかみ   今日起きていること。顔か手が映っているもの。
2〜3    中身     本題。作業の様子、結果、失敗。
4       お願い   スタンプを1つ。アンケート、質問、クイズ、リンクのどれか。
5       締め     答え、結果、または明日への前振り。
```

お願いは7枚目ではなく4枚目に置きます。1枚進むごとに見ている人は減るので、
まだ残っている人にお願いを見てもらいます。

## スタンプと、それぞれの本当の使いどころ

| スタンプ | 役割 | 使うとき |
| --- | --- | --- |
| **アンケート** | 一番気軽に押してもらえる | 情報より反応の数がほしいとき |
| **質問** | 見ている人がそのまま使う言葉を集める | ネタや、買わない理由を生の言葉で知りたいとき |
| **クイズ** | 間違えてもらうことで教える | ジャンル内によくある勘違いがあるとき |
| **絵文字スライダー** | 気分の確認 | 大事な用途はない。楽しいが、得るものは少ない |
| **リンク** | プロフィール以外で唯一タップして飛べる場所 | 本当に行き先があるとき（LINE公式、商品ページなど） |
| **カウントダウン** | リマインド登録できる締め切り | 発売、ライブ、締め切り日 |
| **ADD YOURS** | ときどき、フォロワーの外に広がる | ジャンルの誰でも答えられるお題のとき |

一番軽く見られているのが質問スタンプです。集まった答えは全部、見ている人自身の
言葉で書かれたキャプションや、リールのフックや、DMの書き出しになります。
`/ig-reel` にフック型 #16（The Verbatim Question）として渡します。

## ルール

- **1枚目に顔か手を入れる。** 色の背景に文字だけだと飛ばされます。1枚目で、
  残りが見られるかどうかが決まります。
- **1枚に1つのこと。** ストーリーズで長文を読む人はいません。日本語は
  1枚あたり40文字くらいまでを目安にします。
- **文字は真ん中に置く。** 1080×1920なら、上から250pxより上と、1600pxより下には
  置きません。上にはアカウント名の行、下には返信欄が重なります。
- **1人に話しかける。** 「みなさん」ではなく「あなた」に。ストーリーズは、
  DMではないけれど一番DMに近い場所です。
- **自分のフィード投稿を、何も添えずにシェアしない。** インスタで一番飛ばされる
  1枚です。投稿を紹介するなら、コメント欄で何があったか、なぜ見に行く価値が
  あるかを書きます。
- **売るのは投稿ではなくストーリーズで。** 背景を3枚、案内を1枚、実績や
  お客さんの声を1枚。同じ内容をフィードに投稿するより売れて、リーチも減りません。

## DMへの流れを、正直にやる

うまくいく流れはこうです。悩みを言葉にしたストーリー、「それ私です」と言える
アンケートか質問スタンプ、そして答えてくれた1人ずつへの返信。相手が先に
話しかけてくれたから、会話が始まります。

日本でよくあるのは、ストーリーズで「〇〇と返信してくれた方に資料を送ります」と
案内し、DMで渡して、続きはLINE公式アカウントで、という流れです。この場合も
相手の返信が先にあります。

合言葉への自動返信は、プロアカウント向けに、インスタ公式の機能やMetaが
認めた外部ツールで使える正式な機能です。反応していない人へまとめてDMを
送るのはダメで、アカウント制限の原因になります。
ルールはシンプルで、**相手が先に動き、こちらは返事をする**、です。

## 出力

1枚ずつ順番に、画面に映るもの、話すこと・書くこと、使うスタンプを書き、
集まった反応をどうするかも添えます。

```
ストーリーズ  ·  火曜  ·  5枚

1  [自撮り、歩きながら]   「今年3回目の返金依頼。理由は毎回同じです」
2  [画面録画]             契約書の該当部分にマーカー
3  [顔出しで話す]         「OKをもらったかどうかは気持ちの問題。納品日は日付です」
4  [アンケート]           「納品後のOK待ちで困ったことありますか？」  ある / まだない
5  [写真＋文字]           「返信くれた方に、実際の文言を送りますね」

このあと：「ある」に投票してくれた人には1人ずつ返信します。流れはそれだけです。
```

投稿はしません。投稿するのは本人です。
