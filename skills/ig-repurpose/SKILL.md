# ig-repurpose

いい長い素材1つには、投稿4〜6本分が入っています。たいていの人は1本だけ取り出して、
残りを捨てています。

## 用意してもらうもの

文字起こし、記事、メルマガ、台本、通話のメモ、ライブ配信など。
URLを渡されて、このセッションに文字起こしの道具があれば使います。
なければ中身を貼ってもらいます。何かを取り出す前に、全部読みます。

本人が撮った動画なら、動画ファイルももらいます。本人の言葉を読み直したリールより、
本人の映像を使ったリールのほうが強いからです。

## 要約しない、抜き出す

動画の要約はリールになりません。要約を見たい人はいません。素材を最初から見て、
単体で成り立つものを抜き出します。

| 抜き出すもの | 中身 |
| --- | --- |
| **主張** | 議論になりそうな文、全部 |
| **数字** | 金額、費用、時間、割合、全部 |
| **エピソード** | 人と場面と代償がある瞬間、全部 |
| **仕組み** | 「実はこういう仕組みで…」という説明、全部 |
| **失敗** | うまくいかなかったと認めている部分、全部 |
| **名言** | そのまま引用できる1文、全部 |

何かを書く前に、見つかったものを件数つきで並べます。4つ未満しかなければ、
素材が薄いということです。そこから4本絞り出しても、4本とも薄くなります。
そう伝えます。

## 抜き出したものごとに形式を決める

全部がリールではありません。

- **主張、失敗、エピソード** はリールに。声と顔が要ります。
- **仕組み、番号つきリスト** はカルーセルに。読み返されるものです。
- **引用できる1文** は投稿ではなくストーリーズの1枚に。

## 1週間を組む

抜き出したもの1つが投稿1本になり、どの投稿も単体で完結させます。見る人は元の
素材を見ていませんし、これからも見ません。「この前の動画でも話したんですが」とは
書きません。その投稿が本体です。

それぞれに `ig-reel/hooks.json` のフック型を割り当て、型をばらけさせます。
同じ素材から同じ形のフックで5本出すと、量産工場に見えます。実際そうなので。

本人の動画が素材なら、**実際の映像を使います**。本人がそのことを言った瞬間の、
本当の反応が入ったクリップは、撮り直しよりずっと強いです。切るのは文の切れ目で、
息つぎのところではありません。

週の並びは、一番強い主張を最初に、エピソードを週の真ん中に、仕組みを最後に置きます。
前の投稿を気に入った人が、続きを待っているタイミングになります。

## 出力

```
素材：「初回ヒアリングの通話をやめた理由」（42分のポッドキャスト、約15,000字）

見つかったもの  主張5、数字9、エピソード3、仕組み4、失敗2、名言7

1週間
火  リール      #2  Negative Command   初回ヒアリングの通話はやめていい
                                       14:20のクリップ。最後に本人が笑うところまで
水  カルーセル  Job B キャプション     通話の代わりになった4問のフォーム
金  リール      #21 Mid-Sentence       「…で、その9日後に返金してほしいって言われたんです」
日  リール      #5  Time Collapse      リンクを1つ消したら、週6時間戻ってきた

「火曜の分を書いて」と言ってもらえれば下書きします。
```

下書きは頼まれたら1本ずつ、`/ig-reel` と `/ig-human` を通して作ります。
4本分の台本を一度に出すことはしません。全部同じ調子になって、
結局1本も撮られなくなるからです。
