# ig-profile

ここでは、ほとんどの人が違う所を整えています。プロフィールは、ゆっくり眺められる
お店ではありません。1本のリールから来た人が**フォローするか決める画面**です。
持ち時間は3秒くらいで、答えるべき問いは1つです。「さっきのみたいなのが、ここに
もっとある？それは自分向け？」

## 入力

本人に貼ってもらうか、スクリーンショットをもらいます。名前欄、ユーザーネーム、
自己紹介文、リンク先、ハイライトの名前、固定している投稿、投稿一覧の最初の9枚の
表紙。プロフィール上部と投稿一覧の最初の2列が写ったスクリーンショットがあれば、
1回目は足ります。

本人の代わりに Instagram にログインはしません。

## 採点する

このフォルダの `rubric.json` を読みます。12項目、合計100点。各項目に満点の状態と
よくある失敗が書いてあります。全項目を採点し、表にして、合計を出します。正直に
付けます。1回目はほとんどのプロフィールが30〜40点台です。甘い点は役に立ちません。

```
プロフィール採点  38/100

  名前欄             2/12   名前だけで、検索される言葉がない
  自己紹介の1行目    3/12   「ママ｜カフェ好き｜旅行」と絵文字
  固定投稿3つ        0/10   何も固定していない
  ハイライト         2/8    「日常」「その他」「2023」
  投稿一覧の見え方   4/8    9枚中6枚が話している途中の顔で、文字がない
  ...
```

## 書き直す順番

失った点が大きい順に直します。全部を一度に書き直さないこと。本人が1つずつ
実際に設定を変えに行くからです。

**1. 名前欄（30字まで）。** アイコンの下の太字の行で、ユーザーネームとは別です。
Instagram の検索が照らし合わせるのはここで、多くの人は名前だけ入れて終わっています。
日本でよく使われて効く形は `名前｜何をしている人か（検索される言葉で）` です。
例: 「ゆか｜3分でできる作り置き」「たろう｜会社員の新NISA入門」。
検索は日本語の言葉でも引っかかるので、人が検索窓に打つ言い方を入れます。
「料理」より「作り置き」「時短レシピ」のように、具体的なほうが当たります。
候補を3つ出します。区切りは「｜」がよく使われますが、「/」や「@」でもかまいません。

**2. 自己紹介の1行目。** 誰向けで、見ると何が変わるのか。肩書きでも、形容詞でも、
「｜」で区切った自己紹介の羅列でもありません。残りの150字には、実績を1つか、
はっきりした提供内容を1つ入れます。

**3. 固定投稿3つ。** 3枠に3つの別の役割を持たせます。いちばん強い実績、提供内容の
いちばんわかりやすい説明、本人のことがいちばん伝わる自己紹介。プロフィール全体で
いちばん効く直しで、4回タップすれば終わります。固定していないと、一番上は
たまたま最後に投稿したものになります。運まかせです。

**4. ハイライト。** 4〜6個。お客さんが実際に聞く質問の名前にします。
「料金」「実績」「使い方」「はじめての方へ」など。「日常」「その他」ではなく。
ほかは消します。

**5. リンク。** 自己紹介文で約束した内容に合う行き先を1つ。5つまで貼れますが、
2つの時点でもうメニューです。メニューは1枚の扉より成約しにくいです。
公式LINEに誘導するなら、リンクはそれ1つにします。

**6. 投稿一覧の表紙。** 最初の9枚をサムネイルの大きさで見ます。リールの表紙は
最初のコマのまま放っておかず、選びます。表紙に10字前後の文字があると、一覧が
ひと目で読めるようになります。

## 出力

採点表のあと、直す順にコピーできる書き直しを出します。それぞれ `/ig-human` に
かけてから出します。最後にもう一度採点して、差を正直に見せます。書き直しで
98点ではなく84点なら84点と言い、残りに何が要るかを伝えます。たいていは、
投稿一覧、ストーリーズの習慣、まだ存在しない固定投稿です。どれも書き直しでは
埋まりません。

このスキルは Instagram に何も保存しません。各項目を変えるのは本人です。
