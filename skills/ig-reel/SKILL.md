# ig-reel

思いつき1つを、最後まで見てもらえるリールにします。

このフォルダには、実際に動く道具が2つあります。使ってください。
フックを目で見て判断したり、長さを勘で決めたりしないでください。

```bash
python hookscore.py hooks.txt              # フック案に順位を付ける
python hookscore.py --hook "一言"          # 1本だけ採点する
python beats.py script.txt --target 30     # 撮る前に秒数つきのビート表を作る
```

どちらも Python 3 の標準ライブラリだけで動きます。

## 書く前に

1. `~/.claude/instagram/voice.md` があれば読みます。本人の話し方のメモです。
   カメラの前でどう話すか、絶対に言わない言葉、誰に向けて話しているか、が書いてあります。
   なければ、**本人のリールを3本**もらいます。文字に起こすか読むかして、話し方をつかみ、
   ファイルに書きます。本人が声に出して言う台本なので、話し方が違うと使えません。
2. このフォルダの `hooks.json` を読みます。型が26個あります。
   それぞれにテンプレート、記入例、画面用の文字、向いている用途、よくある失敗が付いています。
   うち4つは、型をそろえるためでなく、実際のフックに何度も出てきたので入っています。
3. 思いつきが薄いときは、水増ししません。質問をまとめて1回だけします。
   何が起きたか、誰に起きたか、何を失ったか、何が返ってきたか。
   リールには、具体的で本当のことが1つ必要です。書く前にそれをもらいます。
4. `~/.claude/instagram/swipe.md` があれば読みます。`/ig-viral` が書くファイルで、
   本人のジャンルで今どの型が効いているかの、本人自身の証拠です。
   このファイルの初期値より優先します。

## 形

リールは最初の2秒で決まり、次の5秒で残ってもらえます。

```
0:00 - 0:02   フック      言い切り。話す一言と画面の文字を、別々に書きます。
                          最初のコマに動きを入れます。止まった顔だけにしません。
0:02 - 0:07   懸かるもの  見ている人にとって、なぜ大事か。1行です。
0:07 - ...    本体        1ビートに1つの話。ビートごとに画を変えます。
最後の3秒     回収        フックで約束したものを渡し、お願いを1つだけします。
最後の一言    ループ      フックの言葉を1つ繰り返し、2回目の再生をきれいにつなげます。
```

長さ: 15〜45秒が使いやすい範囲です。リールは3分まで出せますが、ほとんどの人は使わなくていいです。
7秒未満だと、ループ回数だけが増えて、ほかは何も増えません。

### 日本語の長さの目安

英語版は「1分あたりの単語数」で測っていましたが、日本語には単語の区切りがありません。
この日本語版は**モーラ（拍）**で測ります。「きゃ」は1、「ー」「っ」「ん」は1と数える、俳句の音の数え方です。

- ふつうに話す速さは、だいたい毎秒6〜8モーラです。道具は**毎秒7モーラ**を基準にしています。
- 漢字かな混じりの文字数に直すと、だいたい**毎秒5〜6文字**です。
- フックの目安は2〜3秒なので、**約15〜20モーラ、文字数で12〜18文字くらい**です。
- 30秒のリールなら、台本は全部で**約150〜180文字**です。

モーラの数え方は目安です（かな1字=1、漢字1字=1.8、数字や英字は別の目安）。
漢字の読みは辞書なしでは決められないので、多少ずれます。
自分の台本を声に出して時間を測ったら、`beats.py --mpm` に自分の速さを入れてください
（ゆっくりめは360、早口は480くらいです）。

## 進め方

**1. フックを3つ選ぶ。1つではありません。** 思いつきを `hooks.json` に照らし、
本当に合う型を3つ選び、それぞれ話す一言と画面の文字を書きます。
違う型を3つです。1つの言い換えを3つではありません。

**2. 採点する。** 話す一言を3つ、1行に1つずつファイルに入れ、`hookscore.py` を実行します。
順位を本人に見せます。1位が50点未満なら、まだフックがありません。いくら直しても変わりません。

**3. 台本を書く。** 勝ったフックで書きます。本人がふだん話す言葉で書きます。
短い文にします。練習しないと言えない文は入れません。
書き言葉の「〜である」「〜と言える」は使いません。

**4. 尺を測る。** `beats.py script.txt --target {長さ}` を実行します。指摘はすべて直します。
3秒を過ぎるフック、4秒を超えるビート、具体的なものがない行の連続、ループなし、です。
指摘が消えるまで繰り返します。

**5. 人間らしくする。** 見せる前に `/ig-human` に通します。
書いた文っぽい一言は、声に出した瞬間に分かります。

**6. まとめて出す。** 台本をコードブロックで、画面の文字を秒数つきの別リストで出し、そのあとにこれを出します。

```
REEL READY
フック:     #3 誰も教えてくれない、86点 STRONG
長さ:       28.4秒・9ビート・毎秒7モーラ
画面文字:   6枚
人間らしさ: 不自然な箇所4つを削除、人間らしさ81点 PASS
キャプション: 次は /ig-caption を実行

記録するなら「はい」、直したいところがあれば教えてください。
```

**7. 投稿はしません。** このスキルが作るのは台本までです。撮って投稿するのは本人です。
「はい」と言われたら、`~/.claude/instagram/log.md` に日付、使った型、最初の一言を追記します。
あとで `/ig-audit` が履歴として使います。

## 画面の文字は、別の台本です

毎回、別に書きます。画面の文字は、声より先に読まれます。

- **1枚15文字以内。** まだ音を聞いていない人が、腕を伸ばした距離で読みます。
  大きな文字で2行、1行7〜8文字が目安です。
- **フックの文字は最初のコマから出します。** 無音の間を置いてから出しません。
- **安全な範囲に収めます。** 1080x1920 の画面なら、上から230px より上、1440px より下には置きません。
  右端の230px も空けます。その外側には、キャプション、いいね等のボタン、音源の帯がかぶります。
- **フックをキャプションの位置に置きません。** 画面の下の方は隠れます。
- **本体には字幕を焼き込みます。** 多くの人は最初、音を消して見ます。

## 差が出るルール

- **1本のリールに話は1つ。** 台本に話が2つあるなら、リールが2本です。そう伝えます。
- **形容詞より数字。** 「めっちゃ稼げた」より「18万円」です。
  本人が数字を出していなければ、穴を避けて書かずに、数字を聞きます。
- **前置きを切ります。** あいさつ、「今日は〜について」、名乗り、ロゴの演出は入れません。
  動画は、ふだんなら6秒目に言う文から始めます。
- **ビートごとに画を変えます。** 同じ画が8秒続くところで人は離れます。`beats.py` が指摘します。
- **最後のお願いは1つ。** キーワードをコメント、保存、フォローのどれか1つです。
- **作り話はしません。** 本人の名前で、架空の数字、顧客、売上、成果を書きません。仮の値としても書きません。
  数字が必要で分からないときは、台本に `{{あなたの数字}}` と残して、そう伝えます。
- **本人が使えない流行りの音源を前提に台本を書きません。** 本人の声が必要な内容なら、そう伝えます。

## 採点の道具について

`hookscore.py` は、長さ、具体性、懸かるもの、前のめり（大事な言葉が前にあるか）、呼びかけの5つで、
文字だけを見て採点します。あいさつ、前置き、具体的なものがないフック、長すぎるフックを見つけるのは得意です。
まともなフック2本のどちらが伸びるかは分かりません。それは顔、編集、音、配信先で決まります。

英語版の原作は英語のフックで検証されていますが、その数字は日本語版には当てはまりません。
日本語版の基準は経験則で決めた目安で、まだ検証していません。
最後は、実際の視聴維持のグラフを信じてください。

## 例

```
/ig-reel テンプレート1枚で、提案書づくりが5時間から20分になった
```

```
フック  （採点済み）
  76  STRONG  #1  損した告白     「書式を整えるだけで、2年間毎週4時間使ってました。」
                                 画面: 2年間ムダにした
  73  STRONG  #5  時短型         「提案書、前は5時間でした。今は20分です。」
                                 画面: 5時間 → 20分
  37  WEAK    #9  パクってください 「その提案書テンプレ、そのまま使ってください。」
                                 画面: これ、パクってOK
                                 （数字がないので弱い。「4行の」など数字を足すと上がります）

上の2本はどちらも合格で、点の差は誤差の範囲です。#5 で撮ります。
比率が信じられる範囲で、画面で一瞬で読めて、数字が本人のものだからです。
```
