# voice.md

このファイルを `~/.claude/instagram/voice.md` にコピーして、埋めてください。
パックのどのスキルもこれを読みます。ここに10分かけるかどうかで、そのまま撮れる
台本になるか、毎回書き直す台本になるかが変わります。

手で埋めるのが面倒なら、自分のリールかキャプションを3つClaudeに送って
「これを見て voice.md を書いて」と頼むこともできます。自分で考えて埋めるより、
そのほうが当たります。

インスタでは、このファイルがほかの場所より大事です。台本は声に出して読むからです。
自分なら絶対に言わないセリフは、下書きではなく撮り直しの原因です。

## 話し方

- **一番自分らしいリールかキャプションを3つ：**（貼り付け）
- **一人称：**（私 / わたし / 僕 / 俺 / 自分 / 名前呼び）
- **敬語かタメ口か：**（です・ます / タメ口 / 基本敬語でときどきくだける）
  ※キャプション、リール、コメント返信、DMで変えるなら、それぞれ書く
- **よく使う語尾：**（例：〜です / 〜なんです / 〜だよ / 〜よね / 〜じゃん）
- **カメラの前の自分：**（早口でテンション高め / 淡々 / 落ち着いている / 面白い / 真顔でボケる）
- **よく使う言葉・口ぐせ：**
- **絶対に言わない言葉：**（例：「〜しちゃいましょう」「爆伸び」「神」「ぶっちゃけ」）
- **使ってほしくないAIっぽい言い回し：**（例：「〜することが重要です」「いかがでしたか」
  「さまざまな」「〜と言えるでしょう」「魅力的な」）
- **方言：**（使わない / ときどき / いつも。使うならどこの言葉か）
- **くだけた言葉や強めの言葉：**（使う / 軽くなら / 使わない）
- **キャプションの絵文字：**（使わない / 1つくらい、たまに / わりと使う）
- **よく使う絵文字・顔文字：**
- **顔出し：**（いつも / ときどき / 顔出しなし）
- **ナレーションか、カメラに向かって話すか：**
- **話す速さ：**（台本を読んで計ったことがあれば。`beats.py --wpm` に渡す値です。
  英語の1分あたりの単語数を前提にした設定なので、日本語なら1分あたりの文字数も
  あわせてメモしておくと尺を見積もりやすいです。日本語はだいたい300〜350字/分）
