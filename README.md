# インスタ運用スキル（日本語版）

インスタのアカウント運用を手伝う、Claude Code 用のスキル13個です。無料・MIT ライセンスで、会員登録も API キーもいりません。外部サービスにつなぐ必要もありません。

元になっているのは、Jake Schincariol さんが英語で公開している [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)（MIT）です。ヒトリが日本語で使えるように作り直しました。手順書を訳しただけではなく、英単語の数で点数を出していた計算を、日本語の文字数・読みの長さ・言い回しで測るように書き換えています。

> **使う前に:** フォロワーや再生数が伸びることを約束するものではありません。点数はあくまで目安です。

できることの例です。

- ネタを1つ渡すと、リールの台本を書きます。26種類のフックの型から3案出して、撮る前に採点します。
- 自分のジャンルで伸びているリールを探して、そのアカウントのふだんの再生数の何倍伸びたかで並べます。
- キャプションを書いて、フィードで「…続きを読む」の前にどこまで見えるかを、そのままの形で見せます。
- プロフィールを100点満点で採点して、点を落とした所から書き直します。
- 1週間の投稿計画を立てます。

ほかのスキルを使える水準にしているのが「AIっぽさ消し」（/ig-human）です。下書きから、AIが書く日本語にありがちな言い回し、長いダッシュ、`**` や `#` などの記号、目に見えない文字を取り除いて、5つの項目で採点してから見せます。

**あなたがOKと言うまで、何も投稿しません。** スキルが作るのは下書きまでで、投稿するのはあなたです。

## 入れ方

Claude Code に、次の文をそのまま貼ってください。

```
https://github.com/hitori-claude/instagram-agent-skill-ja

このスキルを入れて、/ig-reel が動くか確かめて。
```

自分でコマンドを打って入れる場合（Mac・Linux）:

```bash
git clone https://github.com/hitori-claude/instagram-agent-skill-ja.git
mkdir -p ~/.claude/skills
cp -r instagram-agent-skill-ja/skills/ig-* ~/.claude/skills/
```

Windows（PowerShell）の場合:

```powershell
git clone https://github.com/hitori-claude/instagram-agent-skill-ja.git
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse instagram-agent-skill-ja\skills\ig-* "$env:USERPROFILE\.claude\skills\"
```

プラグインとして入れる場合:

```
/plugin marketplace add hitori-claude/instagram-agent-skill-ja
/plugin install instagram-agent-ja
```

ひとつの作業フォルダだけで使いたいときは、`skills/` の中の `ig-` で始まるフォルダを、その作業フォルダの `.claude/skills/` にコピーします。

Claude Code 以外のチャットで使うときは、`SKILL.md` を1つ、チャットの最初に貼れば、そのスキルとして動きます。ただし採点用のツール（Python）は動かないので、`/ig-reel` と `/ig-human` は大事なところが欠けます。

**英語版や、ほかの日本語版と一緒には入れないでください。** コマンド名（/ig-reel など）が同じなので、どれか1つにします。

ツールを動かすには Python 3 が必要です。ほかに入れるものはありません。Windows で `python3` が見つからないと出たら、`python` か `py` に置き換えてください。

入れたら、最初に `templates/voice.md`（話し方の設定）を埋めてください。`~/.claude/instagram/voice.md` にコピーして自分で書くか、自分のリールを3本 Claude に渡して「これを元に voice.md を書いて」と頼みます。どのスキルもこのファイルを読みます。リールは台本を自分の声で話すので、ほかの SNS よりこの設定が効きます。

## 13個のスキル

| コマンド | できること |
| --- | --- |
| `/ig-reel` | ネタ1つからリールを作ります。[26種類の型](skills/ig-reel/hooks.json)からフックを3案出して採点し、台本・テロップ・秒割り表まで書きます。 |
| `/ig-viral` | 自分のジャンルで伸びているリールを探して、各アカウントのふだんの再生数（中央値）の何倍かで並べます。フックの型を見分けてメモにまとめます。 |
| `/ig-caption` | キャプションを書いて点検します。「…続きを読む」の前に見える部分をそのまま確認できます。 |
| `/ig-carousel` | カルーセルを作ります。めくりたくなる表紙、1枚ずつの文面、1080×1350 の画像まで。 |
| `/ig-story` | 毎日のストーリーズの流れを作ります。どのスタンプを何に使うか、相手から話しかけてもらって DM につなぐ流れも含みます。 |
| `/ig-profile` | プロフィールを[12項目の採点表](skills/ig-profile/rubric.json)で100点満点で採点して、直す順に書き直します。 |
| `/ig-plan` | 1週間の計画を立てます。何を、どの形式で、いつ出すか。交流する10アカウントも決めます。 |
| `/ig-human` | AIっぽさ消しです。文章を直すツールと、採点するツールの2つが入っています。 |
| `/ig-comment` | 他の人の投稿へのコメントを書きます。9つの型から、投稿の中身に合うものを選びます。「🔥🔥🔥」は書きません。 |
| `/ig-reply` | 自分の投稿についたコメントへの返信を書きます。合言葉・見込み客・中身のある感想・質問・応援・返さなくていいもの、に分けて、この順に返します。 |
| `/ig-dm` | DM を書きます。合言葉をくれた人への特典の送付、最初のメッセージ、コラボの相談、追いメッセージ（2回まで）。 |
| `/ig-repurpose` | 動画・ポッドキャスト・メルマガ1本を、それぞれ単体で成り立つ1週間分のリールとカルーセルに作り直します。 |
| `/ig-audit` | 出した投稿を振り返ります。再生数ではなく、伸び倍率とリーチあたりのシェア数で並べます。 |

## 実際に動くツール

ネットにはつながらず、何もアップロードしません。あなたのパソコンの中で、あなたの文章だけを読みます。

### フック

```bash
python hookscore.py hooks.txt              # フック案を点数順に並べる
python beats.py script.txt --target 30     # 撮る前に秒数を測る
```

`beats.py` は台本の1行ずつにかかる秒数を見積もって、タイムコードを並べます。そのうえで、リールが編集で死ぬ4つの原因を指摘します。3秒を超えるフック、見ている人が離れるほど長い1カット、具体的なものが何も出てこない行の連続、最初の行に戻ってこない終わり方、の4つです。

### キャプション

```bash
python caption.py caption.txt --keywords "朝活,時短"
```

フィードではキャプションの頭の数行しか見えず、残りは「…続きを読む」の後ろに隠れます。うまくいかないキャプションの大半は、ここで負けています。なので最初に、通りすがりの人が見るとおりの範囲を枠で表示します。

日本語は1文字が英数字のほぼ2文字分の幅を取るので、文字数ではなく表示幅で数えています。見える幅はスマホの機種や設定で変わるため、近い値での目安です。

ハッシュタグは1投稿5個までを基準にしています（2025年12月に30個から5個に減りました）。

### AIっぽさ消し

```bash
python humanize.py draft.txt --report      # きれいにして、直した所を全部見せる
python detect.py draft.txt                  # 5つの項目で採点する
python detect.py before.txt after.txt       # 直す前と後の差を見る
```

**自動で直すもの:**

- **見えない文字。** ゼロ幅スペースなど、キーボードでは打たない文字です。コピペでも残り、どのエディタでも見えません。
- **記号。** 長いダッシュ、`**` や `#` などのマークダウン記号。
- **AIっぽい言い回し。** 「〜と言えるでしょう」「いかがでしたか」「〜することが重要です」など。一覧は [`slop.json`](skills/ig-human/slop.json) にあって、自分で書き足せます。

**直さずに指摘だけするもの:** 文の形を変えないと直らないもの（同じ語尾が続く、文の長さがそろいすぎている、絵文字の箇条書き、など）は、正規表現で無理に直すと意味が崩れるので、書き直しの候補として返します。

### スワイプファイル

```bash
python swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

再生数そのものは証拠になりません。フォロワー200万人のアカウントの40万再生は、静かな火曜日です。フォロワー4,000人のアカウントの40万再生は、何かを当てています。`swipe.py` は、各アカウントのふだんの再生数（中央値）の何倍伸びたかで並べ、フックの型を見分けます。「1.2万」「3,400」のような日本の数字の書き方も読めます。

## 点数について（ここは正直に）

英語版の作者は、フックの採点を英語のショート動画74本で試していて、「明らかに弱いフックを見分けるのは得意（AUC 0.83）、当たりと外れを見分けるのはほぼ運（AUC 0.56）」と書いています。

日本語版は、測り方そのものを日本語用に作り直したので、**英語版のこの数字は日本語版には当てはまりません。** 日本語のリールで同じ検証はまだしていません。点数は「あいさつから入っている」「具体的な数字や名前がない」「3秒で言い切れない」といった、はっきり弱いフックを落とすための目安として使ってください。2つのまあまあのフックのどちらが伸びるかは、文章からは分かりません。顔、編集、音、インスタが誰に見せるかで決まります。最後は自分の視聴維持率のグラフを信じてください。

## 注意書き

**このスキルはインスタに投稿しません。** プロアカウント向けの公式の投稿 API はありますが、Meta の開発者アプリ、ページの連携、長期トークン、アプリ審査が必要で、スキルで渡せるものではありません。投稿・コメント・フォロー・DM を自動でやる手段の多くは、ブラウザの自動操作か外部ツールで、どちらも[インスタの利用規約](https://help.instagram.com/581066165581870)に反し、アカウントが制限される原因になります。なので、どのスキルも最後は「そのまま貼れる文章」で終わり、投稿はあなたがします。

例外は、コメントの合言葉に DM で自動返信する仕組みです。インスタ自身の機能や認定パートナーのツールで使えて、相手が先にコメントしたときだけ動きます。`/ig-dm` に、どこまでが大丈夫かを書いています。

**`/ig-viral` は読むだけで、自動収集はしません。** 10アカウント・各十数本を、人と同じ速さで、あなたが自分のブラウザで見ます。パスワードを聞くことも、あなたとしてログインすることもありません。

**AIっぽさの採点は、パソコンの中で動く目安です。** 外部の AI 判定サービスを呼んでいるわけではなく、その判定結果を約束するものでもありません。

**数字を作りません。** あなたの名前で、作り話の数字・お客さん・成果を書くことはしません。必要な数字が足りないときは、`{{あなたの数字}}` と書いて、印を付けて返します。

**インスタの仕様は変わります。** この文書と実際のインスタが食い違っていたら、インスタのほうが正しいです。
